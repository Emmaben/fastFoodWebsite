# 🍔 FastFood Landing Page

A simple one-page fast food website built using **HTML and CSS**.  
This project was created as part of my early frontend development learning to practice layout structuring, styling, and responsive design.

---

## 🚀 Features

- Clean and modern landing page design
- Hero section with background image
- Navigation bar with links
- Call-to-action button ("Our Menu")
- Responsive layout (basic responsiveness depending on implementation)
- Custom typography and styling

---

## 🛠️ Tech Stack

- HTML5
- CSS3

---


---

## ▶️ How to Run the Project

### Option 1: Open directly
1. Download or clone the repository
2. Open `index.html` in your browser

### Option 2: Using VS Code Live Server
1. Open the project folder in VS Code
2. Install the **Live Server** extension
3. Right-click `index.html`
4. Click **"Open with Live Server"**
